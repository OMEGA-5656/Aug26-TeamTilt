# TeamTilt

A 2D co-op platformer built in Unity 6 with Netcode for GameObjects multiplayer.

## Features

- Local multiplayer via host/join (LAN)
- Pico Park–style camera that zooms to keep all players on screen
- Custom kinematic 2D physics (movement, jumping with coyote time, dashing)
- Level progression with unlocks, saved locally
- UI Toolkit screens (main menu, lobby, level select, settings, pause)

## Requirements

- Unity 6000.0.71f1 or newer
- Windows / Android

## Getting Started

1. Open the project in Unity.
2. Open **Window > Package Manager** and confirm `com.unity.netcode.gameobjects` and `com.ivanmurzak.unity.mcp` are installed.
3. Open the **Bootstrap** scene and press Play, or build for your platform.

## Builds

- **Windows:** `TeamTilt > Build Windows` menu item → `Builds/Windows/TeamTilt.exe`
- **Android:** `TeamTilt > Build Android` menu item → `Builds/Android/TeamTilt.apk`
